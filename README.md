# Assistència i quotes · Taller de Moviment Creatiu

Web para pasar lista y apuntar las cuotas del Taller de Moviment Creatiu (Casal de la Dona, Palafolls). Un projecte de l'Associació Laboratori Línia de Fuga.

- **Web:** https://tergiverselab.github.io/assistencia-mc/
- **Base de datos:** hoja de Google «Assistència i quotes · Moviment Creatiu» (Drive › Movimiento Creativo - T2).
- **Puente:** `apps-script.gs` (montado con `gs/build.sh`), pegado en Extensiones › Apps Script de esa hoja.
- **Fuentes de la web:** `web/` (se montan en `index.html` con `web/build.py`).
- Loli (Casal de la Dona): 15 % de las cuotas de cada mes + 20 € por alta del Casal; pestaña «Loli» en la hoja y bloque en Cuotas.
